# Universal Tool (万能工具)

面向 **Minecraft 1.21.1 NeoForge** 的综合功能扩展模组。融合全能工具、时钟聚合合成、时空折跃与致敬《瑞克和莫蒂》的「凤凰计划」生命重塑体系。

---

## 🌟 核心特色与功能

### 1. 五合一万能工具 (Universal Tools)
- **多工合一**：集成原版镐、斧、铲、锄、剑全部采掘与战斗特性；
- **全交互覆盖**：右键支持剥树皮、刮铜除蜡、耕地、制土径与灭营火；
- **材质梯度**：涵盖木、石、铁、金、钻石、下界合金六档，耐久全面提升 1.5 倍以补偿制作成本；
- **金质特调**：保留 12.0 极速挖掘效率，特调高达 3.2 攻击速度。

### 2. 万能聚合台 (Universal Polymerizer)
- **时钟表盘设计**：中心聚合核心与周围 12 个时钟方位环形输入槽；
- **无序集合匹配**：原料摆放方位无关，支持一圈高阶材料环绕低阶万能工具进行阶梯升级；
- **JEI 专属分类**：在 JEI 查阅配方时，原汁原味呈现 12 环时钟专属界面。

### 3. 时空法典与折跃系统 (Teleportation System)
- **时空法典**：右键打开时空星盘，记录世界任意点位并支持平稳传送；
- **时空书页**：主手持书页、副手持法典右键拓展坐标容量（12 ~ 36 宫位）；
- **传送卷轴**：支持从法典拓印坐标，分发给队友或快速长按右键折跃。

### 4. Operation Phoenix (凤凰计划)
- **DNA采集注射器**：手持右键吸取自身 1 点生命值，提取专属 DNA 样本；
- **生物营养原液**：手持潜行右键触发全息扫描，**将全身 41 格装备与物资（含完整附魔与耐久）完整量子刻印进原液中**；
- **生化培养仓**：高透八角生化圆柱舱，注入 DNA 与营养原液后经 60 秒孵化生成悬浮沉睡的克隆体；
- **12秒电影级第一人称死亡回归**：
  - 致命伤害自动拦截，绝无死亡屏幕；
  - 经历灵魂出窍回眸、量子超空间折跃、百米高空穿云俯冲扎入培养仓；
  - 仓内眼睑张开与起搏心跳；
  - **正面高透双门向左右平滑液压对开滑移**，伴随高压白烟迈步出舱，全身战备依照快照 100% 完美重塑！

### 5. 玩家私人空间
- **独立基地维度**：每位玩家可创建一个私人基地。新基地的自然岛屿范围为 512×512 方块，岛外为虚空，可自由飞行和扩建；已有基地和岛外建筑不会被裁剪。
- **八种地貌**：创建时可选超平坦、平原、樱花林、沙漠、雪原、白桦林、热带草原或浮空群岛。创建后地貌固定。出生点位于中央安全区域，坠入虚空会返回基地出生点并保留物品。
- **入口与拜访**：入口门绑定放置者；同一玩家的多扇门都通向同一基地。主人可直接进入，访客每次进入都需要输入基地密码；主人离线时访客仍可建造。
- **密码与返回**：潜行并右键自己的入口门可修改密码。基地内的返回门会把玩家送回进入前的位置；无人使用的基地会卸载，并在再次进入或服务器重启后恢复。

**开始使用**：用 8 个哭泣的黑曜石围住合成台中央的 1 个末影之眼，合成私人空间入口门。放置后右键入口门，选择地貌并设置 4–64 个字符的密码以创建基地。之后右键自己的门即可进入；访问其他玩家的门时输入对方密码。

**运行要求**：Minecraft 1.21.1、NeoForge 21.1 或更新版本，以及安装在客户端和服务器上的 Universal Tool。JEI 不属于运行必需依赖。

## 🛠️ 构建与开发

```bash
# 编译
./gradlew build

# 运行开发客户端
./gradlew runClient
```

## 开发

项目使用 Java 21 和 Gradle Wrapper。构建模组：

```bash
./gradlew build
```

Windows PowerShell：

```powershell
.\gradlew.bat build
```

运行开发客户端可使用 `runClient`，运行专用服务器可使用 `runServer`。私人空间 GameTest、视觉验收、像素资源生成和复现步骤见 [`art/validation.md`](art/validation.md)；可编辑门模型位于 `art/assets/`，预览图位于 `art/previews/`。
